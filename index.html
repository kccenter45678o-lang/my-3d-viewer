หัวข้อ 1.1

ความเป็นมาและความสำคัญของปัญหา

วิกฤต PM 2.5 ในสถานศึกษา: ฝุ่นละออง PM 2.5 เป็นภัยเงียบที่ทำร้ายสุขภาพเด็กๆ แต่ความท้าทายคือโรงเรียนมักจะรู้ตัวเมื่อฝุ่นอยู่ในระดับอันตรายไปแล้ว ทำให้ผู้บริหารและครูไม่สามารถวางแผนปรับเปลี่ยนกิจกรรมกลางแจ้ง (เช่น การเคารพธงชาติ หรือวิชาพลศึกษา) ได้ทันเวลา

ข้อจำกัดของระบบเดิม: สถานีตรวจวัดภาครัฐมีต้นทุนสูง ขาดแคลนการกระจายตัว และรายงานผลย้อนหลัง ซึ่งไม่สะท้อนมลพิษระดับจุลภาค (Hyper-local Data)

ทางออกด้วย IoT & AI: การใช้ไมโครคอนโทรลเลอร์ ESP32 ร่วมกับเซนเซอร์ฝุ่นเลเซอร์ PMS5003 และ BME280 สร้างเครือข่ายสถานีต้นทุนต่ำแต่เที่ยงตรงสูง

ประยุกต์ใช้ปัญญาประดิษฐ์ (Random Forest & LSTM) คาดการณ์ระดับฝุ่นล่วงหน้าผ่าน Web Dashboard และแจ้งเตือนอัตโนมัติทาง LINE

คลิปบรรยายปัญหามลพิษฝุ่นละอองที่มาของโครงการ:

หัวข้อ 1.2

วัตถุประสงค์ของโครงงาน

1.2.1

ศึกษาความต้องการ

ศึกษาและสำรวจความต้องการพัฒนาระบบ IoT ตรวจจับฝุ่นและสภาพอากาศล่วงหน้าในสถานศึกษา

1.2.2

พัฒนาระบบ IoT

ออกแบบและสร้างสถานีตรวจวัดคุณภาพอากาศ ร่วมกับระบบ AI วิเคราะห์และคาดการณ์ฝุ่นล่วงหน้า

1.2.3

ประเมินคุณภาพ

ประเมินความเที่ยงตรงของอุปกรณ์และทดสอบความแม่นยำของแบบจำลอง AI คาดการณ์

1.2.4

ศึกษาความพึงพอใจ

ประเมินระดับความพึงพอใจของผู้ใช้งาน ครู นักเรียน และผู้บริหารต่อการใช้งานระบบ

1.3 ขอบเขตของโครงงาน

  • ไมโครคอนโทรลเลอร์ ESP32 รับส่งข้อมูลเรียลไทม์กับ InfluxDB และ Firebase
  • เซนเซอร์ PMS5003 (วัดฝุ่น) และ BME280 (วัดอุณหภูมิ/ความชื้น/ความกดอากาศ)
  • แบบจำลอง LSTM / Random Forest ประมวลผลบน Cloud คาดการณ์ PM 2.5
  • Web Dashboard และระบบส่งสัญญาณแจ้งเตือนผ่าน LINE Notify API

1.6 ประโยชน์ที่คาดว่าจะได้รับ

ด้านนักเรียนและสถานศึกษา: เข้าถึงข้อมูล PM 2.5 ระดับจุลภาค วางแผนป้องกันตนเองและทำกิจกรรมได้อย่างปลอดภัย
ด้านการบริหารจัดการ: ช่วยผู้บริหารตัดสินใจเชิงรุกในการสั่งงดกิจกรรมกลางแจ้ง หรือเปิดระบบฟอกอากาศทันท่วงที
ด้านวิชาการ: สร้างสถาปัตยกรรม IoT ต้นทุนต่ำ และเปิดชุดข้อมูล Hyper-local Time-Series สำหรับต่อยอด
