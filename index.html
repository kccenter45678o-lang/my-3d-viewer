ข้อจำกัดสถานีภาครัฐ: สถานีตรวจวัดคุณภาพอากาศของภาครัฐมีต้นทุนสูงและจำกัดอยู่เฉพาะจุดศูนย์กลางเมือง ทำให้ขาดข้อมูลเฉพาะพื้นที่ระดับจุลภาค (Hyper-local Data) และเน้นการรายงานย้อนหลังมากกว่าการพยากรณ์ล่วงหน้า

จุดเริ่มความต้องการพัฒนาระบบ:

เกิดความต้องการพัฒนาระบบเฝ้าระวังมลพิษระดับพื้นที่ที่มีต้นทุนต่ำ มีความเที่ยงตรงสูง สามารถพยากรณ์ค่าฝุ่นล่วงหน้าผ่าน AI และแจ้งเตือนผ่าน LINE ร่วมกับ Web Dashboard ได้อย่างแม่นยำและทันท่วงที

ขอบเขตการศึกษา

ประชากรและกลุ่มตัวอย่าง: นิสิต บุคลากร และอาจารย์ มหาวิทยาลัยบูรพา วิทยาเขตบางแสน โดยสุ่มกลุ่มตัวอย่าง 30 คนในการสำรวจความต้องการ และ 40 คนในการประเมินความพึงพอใจหลังการทดลองใช้
เนื้อหาและระบบ: ตรวจวัดฝุ่น PM 2.5, PM 10, อุณหภูมิ, ความชื้นสัมพัทธ์ และความกดอากาศ มีระบบชดเชยค่าความชื้นสัมพัทธ์ (Humidity Compensation) ใช้ AI แบบจำลอง LSTM ในการพยากรณ์ฝุ่นล่วงหน้า 3-7 วัน และแสดงผลผ่าน Web Dashboard ร่วมกับการแจ้งเตือนผ่าน LINE Notify (Flex Message)
ฮาร์ดแวร์: บอร์ด ESP32, ESP32 Expansion Board, เซนเซอร์ Plantower PMS5003, เซนเซอร์ Bosch BME280, จอ OLED 1.3 นิ้ว และกล่องเคสกันน้ำระบายอากาศ
ซอฟต์แวร์: Arduino IDE, InfluxDB, Firebase Realtime Database, Netlify, Google Apps Script และ LINE Notify API

2

3

กรอบการพัฒนาตาม ADDIE Model

1. ขั้นวิเคราะห์
(Analysis)

ศึกษาสภาพปัญหา บริบทพื้นที่ มหาวิทยาลัยบูรพา วิทยาเขตบางแสน และสำรวจความต้องการของผู้ใช้ในด้านพารามิเตอร์ ช่องทางแจ้งเตือน และระยะเวลาพยากรณ์

2. ขั้นออกแบบ
(Design)

ออกแบบสถาปัตยกรรม IoT 5 ชั้น (Perception, Transport, Processing, Application, Business), ฮาร์ดแวร์, InfluxDB/Firebase, LSTM, Web Dashboard และ Flex Message

D

3. ขั้นพัฒนา
(Develop)

ประกอบฮาร์ดแวร์, เขียนโค้ด ESP32 กรองสัญญาณรบกวนด้วย Trimmed Mean Filtering, ฝึกแบบจำลอง LSTM, สร้าง Web บน Netlify และเชื่อมต่อ LINE API

I

4. ขั้นนำไปใช้
(Implement)

(Evaluate)

Literature Review

งานวิจัยและทฤษฎีที่เกี่ยวข้อง

เลื่อนตารางซ้าย-ขวาเพื่อดูข้อมูลเต็ม

ผู้วิจัย & ปีที่พิมพ์ เทคโนโลยี / โมเดลที่ใช้ สาระสำคัญและผลการทดลอง
1. กลุ่มงานวิจัยระบบตรวจวัดมลพิษด้วย IoT
Ramadan et al. (2024) IoT + AI (Weighted Class) ใช้ IoT ร่วมกับ AI ตรวจวัดมลพิษอุตสาหกรรม และใช้เทคนิค Weighted Class แก้ปัญหา Data Imbalance เพิ่มความแม่นยำในการเตือนภัยสภาวะวิกฤต
Hura et al. (2024) ESP32 + Wi-Fi Cloud สร้างสถานีตรวจวัดคุณภาพอากาศต้นทุนต่ำด้วย ESP32 ยืนยันการส่งข้อมูลผ่าน Wi-Fi เข้าคลาวด์ได้อย่างมีเสถียรภาพและประหยัดพลังงาน
Tello et al. (2025) Citizen Science + Open Data พัฒนาระบบเฝ้าระวังมลพิษเมืองบนแนวคิด Citizen Science บูรณาการ Open Data และ AI คาดการณ์ฝุ่น เพื่อเสริมการตัดสินใจของชุมชน
2. กลุ่มงานวิจัยการคาดการณ์ฝุ่นด้วย AI / LSTM
Saminathan & Malathy (2024) Bidirectional LSTM (Bi-LSTM) ประมาณค่าฝุ่น PM 2.5 ด้วย Bidirectional LSTM (Bi-LSTM) พบว่าลดค่าความผิดพลาด RMSE ได้ต่ำกว่า LSTM แบบทิศทางเดียวอย่างมีนัยสำคัญ
Naz et al. (2025) AirVCQnet (Hybrid Quantum-LSTM) พัฒนาโมเดลไฮบริด AirVCQnet (VMD + CNN + Quantum-LSTM) ทำนายฝุ่นได้แม่นยำสูงกว่าโมเดลแบบคลาสสิกถึง 14%
Wu et al. (2023) Multivariate LSTM ป้อนข้อมูลอนุกรมเวลาหลายแปรผัน (PM 2.5 ร่วมกับ อุณหภูมิ ความชื้น ลม) เข้าโมเดล LSTM ช่วยลดความผิดพลาดในการทำนายฝุ่นได้อย่างมาก
Zhang et al. (2024) LSTM & Humidity Compensation สำรวจเชิงระบบพบว่า LSTM เหมาะสมที่สุดสำหรับอนุกรมเวลาฝุ่น พร้อมระบุว่าการชดเชยความชื้นสัมพัทธ์ (Humidity Compensation) เป็นขั้นตอนสำคัญที่สุดต่อความแม่นยำ
